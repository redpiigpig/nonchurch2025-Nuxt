# 張辰瑋 寫作風格與流程 Pipeline

> 張辰瑋＝《無境界者》創辦人，截至第 9 期為止全刊最高產作者（34 篇）。寫稿前先讀這份 skill 對齊他的聲音，再依流程取材、成文、上架。
> 上架一律走 [`upload-article`](../upload-article/SKILL.md) skill（含投稿管理備份）。

---

## 一、作者定位與既有作品

- 身分：雜誌創辦人、神學/教會史寫作者；曾讀神學院、後離開教會，自我定位為「屬靈孤兒／旅人／無境界者」。
- 兩大文類（看 DB 既有 34 篇）：
  1. **「我的◯◯史」信仰自傳體**（category 多為 `生命故事`）：我的異端史、我的福音派史、我的大公派史、我的泰澤史、流浪者之聲…第一人稱回憶錄，最能代表他的聲音。
  2. **評論與專題長文**（`評論與回應` / `專題文章`）：教會史、神學主題的考據與評論（如〈尼西亞基督教的形成〉〈主教制的歷史演變〉）。
- 撈範本：`SELECT id,title,content FROM articles WHERE author='張辰瑋' ORDER BY issue`（走 REST，見 [upload-article] 第六節 IPv6 注意事項）。最佳對照：**8-12 我的泰澤史**、**2-10 流浪者之聲**。

---

## 二、聲音特徵（寫稿時對齊這幾點）

- **第一人稱、長而流動的敘事**：以具體場景推進——精確的日期、地點、人名、對話。少抽象說教，多「帶你親歷現場」。
- **誠實到近乎自曝**：不美化自己，坦白承認內傾、需要獨處、叛逆、罪惡感、嫉妒、缺乏同理心。脆弱是他文字的力量來源。
- **神學長在生命經驗裡**：把潘霍華、羅哲、約翰‧衛斯理、赫塞、聖經經文、詩歌歌詞，自然織進親身故事，而不是另闢理論段落。
- **反諷與溫柔的幽默**：即使在沉痛處也有自嘲與荒謬感（如泰澤「通往自由的巴士」、被搶五十歐）。
- **文學性的小標**：`<h3>` 用意象化、有餘味的標題（〈何處有仁〉〈成為時間之賊〉〈流浪漢之夜〉），不用「第一段／背景介紹」這種功能性標題。
- **母題**：教會合一、大公傳統、無境界主義、朝聖／旅人、屬靈父親、孤兒、個體化、神聖與世俗的辯證。
- **收尾**：敘事體文章最後一字接 **🌏**（地球，象徵無境界）。
- 格式同 [interview-article] / CLAUDE.md：全 HTML、`<blockquote>` 引文、`<figure>` 配圖、`footnotes` JSONB、引用標 `<sup class="footnote-ref">`。

## 三、第三文類：AI 對話 → 意識流獨白（9-10 範式）

張辰瑋的素材有一大來源是**他與 AI 的長篇對話**（他自稱「阿周那」、稱 Gemini 為「克里希那」）。這些對話存在**另一個專案** know-graph-lab：

| 素材 | 路徑 |
|------|------|
| 寫作計畫（書名「神，你正在重排我的前途／與克里希那的對話」） | `C:\Users\user\.claude\projects\c--Users-user-Desktop-know-graph-lab\memory\project_krishna_dialogues.md` |
| 對話轉寫作的既有技能（取材機制可複用） | `C:\Users\user\Desktop\know-graph-lab\.claude\skills\dialogues-to-writing\SKILL.md` |
| 每日原始對話 JSON | `C:\tmp\krishna\YYYY-MM-DD.json` |
| 一月手工稿 | know-graph-lab `2026.01對話錄.docx` |

**9-10〈一位牧者之死〉的成文範式**（使用者指定）：
1. **鎖定單一情節線**：只保留與「龐君華會督之死」直接相關的段落（1/15 得知噩耗、1/16 左心泰按牧、1/18 回城中教會主日＋詩歌分享會＋神學頓悟）；**刪掉**夢境、榮格積極想像、場域理論、身體/SM、與死亡無關的生活絮語。
2. **文體**：**意識流的第一人稱獨白**。標題 `一位牧者之死` 直接呼應**契訶夫《一個小公務員之死》**（不是卡夫卡——但卡夫卡式的內在、焦慮、荒謬感可融入）。手法：以「瑣碎細節對照死亡」製造反諷（如得知噩耗時正在計算減肥熱量），長句、聯想式跳接、內在獨白。
3. **三日三段**：用 `<div class="custom-divider"></div>` 分隔 1/15 / 1/16 / 1/18 三個時間段，段內意識流。詩歌、經文用 `<blockquote>`。結尾 🌏。
4. 真實人事保真，**不得虛構**（見下節）。

## 四、鐵則：保真，不虛構（這是他的真實人生）

- 所有人名、日期、事件、引述**只能來自素材本身**。查不到、記不清的，寧可不寫，不要「合理推測」補細節（生卒年、頭銜、地點都易錯）。
- **隱私與敏感揭露要先問**：素材含使用者高度私人的內容（如同志身分、家庭、醫療、對在世第三人的評價）。寫進公開文章前，**逐項標示出來請使用者確認去留**（參 [interview-article] 9.14）。預設保留與「主題核心」直接相關者、刪去無關隱私。
- 詩歌歌詞、經文、引文逐字照抄，不要改寫或「潤飾」。

---

## 五、流程

1. 讀本 skill ＋ 撈 2-3 篇張辰瑋範本對齊聲音。
2. 取材：讀寫作計畫 + 對應日期的 `C:\tmp\krishna\*.json` / 手工稿，**抽出鎖定情節線的逐字片段**。
3. 成文：依文類（自傳體／評論／意識流獨白）寫 HTML；自傳體收 🌏。
4. **先給使用者看草稿**（尤其意識流獨白與含隱私的稿），標出需確認的揭露點，再上架——這是他的個人創作，不要直接寫進 DB 就算數。
5. 確認後，用 [`upload-article`](../upload-article/SKILL.md) pipeline 寫進 articles（`is_published=false`）＋投稿備份。9-10 既有 stub，沿用 id `9-10一位牧者之死`、category `評論與回應`、section `主題廣場`、author `張辰瑋`。
6. 預覽 `/articles/{id}`、校稿、再開 `is_published`。
