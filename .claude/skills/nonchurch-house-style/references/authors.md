# 作者聲音：怎麼查、怎麼用

## ⚠️ 這是「編輯時不要改壞誰的聲音」，不是「模仿誰來寫稿」

**只有張辰瑋需要從概念／素材生成草稿**（走 [`chenwei-essay`](../../chenwei-essay/SKILL.md)）。
**其他所有作者都是直接交完整稿**——從網站投稿系統來，或把 Word 交給編輯部。你的工作是**編輯**：錯字、標點統一、HTML class 套用、腳注格式、圖說補齊、分類與 id 決定。

所以作者聲音檔的用途是：**動別人的稿之前先認得他的文氣，才知道哪些「看起來怪」的地方其實是他的風格，不要動它。**
不要拿它去替人捉刀，也不要因為「這樣寫比較好」就重寫別人的段落。本刊對投稿者的公開承諾是「原則上維持作品原貌，僅進行錯別字、語詞誤用、格式調整等校對，並會與原作者協商」。

## 一、完整的作者聲音檔在哪

**專案裡已經有一套完整的、逐位作者的聲線檔**，不要再另寫一份：

```
.agents/skills/preserve-nonchurch-author-voice/
├── SKILL.md                       ← 使用方法、證據等級、四種工作類型的改寫幅度
├── references/author-index.md     ← 48 位作者索引（ID、證據等級、檔案連結）
└── references/authors/NN-姓名.md  ← 逐位：聲線 / 模式 / 編輯護欄 / 代表作
```

> 這套 skill 放在 `.agents/`（給 Codex 等其他 agent 用），Claude 的 skill 清單看不到它，但**檔案讀得到**。動任何一位作者的稿之前，照下面兩步走。

### 用法

1. 先讀 [`author-index.md`](../../../../.agents/skills/preserve-nonchurch-author-voice/references/author-index.md) 找到那位作者，看他的**證據等級**：
   - `穩固`（≥3 篇親筆）→ 可以放心依他既有的文類模式編輯
   - `暫定`（1–2 篇）→ 只保留可直接觀察的特徵，不要推論
   - `口語限定`（證據主要來自訪談回答）→ 只用在訪談整理，不能拿來改他的書面文章
   - `不足`（翻譯、配音、圖說）→ **不推定文風**，照一般編輯規範走
2. **只讀那一份** `authors/NN-姓名.md`，不要一次載入全部。每份含：聲線、模式（同一人常有 2–3 種）、編輯護欄、代表作 id。

### 幾個容易踩的點

- **`linked_author_ids` 只表示關聯，不等於文字作者**。專訪的文字作者是訪問者＋編輯部，不是受訪者。
- **署名角色要分清**：親筆作者 / 共同作者 / 受訪者 / 訪問者 / 翻譯 / 配音。7-6 那種「文：張辰瑋｜圖：Gemini生成｜台文翻譯：Chô Nâsim｜有聲書配音：邱蕾州」的複合掛名，每個角色的文字歸屬都不同。
- **同一人有多種模式時挑一種**，按新稿的素材與文類選；除非原稿本來就混合，不要把所有特徵揉在一起。
- 有新作品時跑一次覆蓋率稽核：
  ```bash
  node .agents/skills/preserve-nonchurch-author-voice/scripts/audit-author-coverage.mjs
  ```

## 三、編輯任何人的稿：能動 vs 不能動

**可以動的**（這就是編輯部的工作）：

- 錯別字、贅字、明顯的語詞誤用
- 標點統一：破折號 `──`、中英之間半形空格
- HTML class 套用與修正（見 [`../SKILL.md`](../SKILL.md) 第二節）
- 清 Word 殘留（`MsoNormal`、裸 `<span style>`、空 `<p>`）
- 腳注格式正規化（`<sup class="footnote-ref">` + JSONB）
- 圖說補齊、授權標註
- 收尾補 🌏（全刊規則）
- 決定 `category` / `section` / `id` / `sort_order` / `keyword` 格式
- 幫忙寫 `summary`（投稿者填的 `article_summary` 可以直接用或修短）
- 小標的**編號**要拿掉（memory `feedback_writing_style`）

**不要動的**：

- 論點、結構、段落順序
- 作者的用詞習慣：港式詞彙（和理非、勇武派）、日文漢字（内村、日録）、「臺」vs「台」、口語程度、感嘆號密度
- 小標的措辭（除了編號）
- 腳注的學術內容——可以改格式，**不能改或刪出處**

**絕對不要做的**：

- **替作者虛構事實**——生卒年、學歷系所、書名、機構名一律查證或不寫（[`interview-article`](../../interview-article/SKILL.md) 9.6 有完整的捏造事實清單）
- 替作者「補全」他沒寫的出處
- 自己決定隱私、對在世第三人的批評要不要留——逐項標出來問使用者
- 把所有文章修成同一種「雜誌腔」

**動幅超過錯字與格式時要先問**（編輯原則就是「會與原作者協商」）。

## 四、特稿專區的外部作者

特稿多半是學者、法師、牧師、運動者的邀稿或轉載，多數在作者索引裡是 `暫定` 或 `口語限定`——**改動幅度要更保守**。

- **轉載稿**在 `remark` 寫清楚原始出處與授權：`本文曾刊登在衛理神學院網站上[^1]`、`本文曾發表於義光教會刊物上，今得作者本人同意，再度刊登。`（`[^N]` 是這些欄位的正確寫法，見 [`../SKILL.md`](../SKILL.md) 3.2）
- **稱謂照原樣**：`溫金柯老師`、`昭慧法師`、`龐君華會督`、`陳欽生前輩`、`田孟淑長老`。`author` 欄位用全稱，內文對話用簡稱。
- 學術稿的徵引體例交給作者，只補明顯缺漏。
