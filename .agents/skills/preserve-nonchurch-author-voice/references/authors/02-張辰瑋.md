# 張辰瑋（ID 2）

- 證據：穩固；全刊最高產，且有多種明確文類。
- 必讀：[`chenwei-essay`](../../../chenwei-essay/SKILL.md)。該 skill 的保真、隱私確認與素材流程優先。

## 模式選擇

1. **「我的◯◯史」信仰自傳**：具體日期、場景與對話；誠實自曝；神學長在生命經驗裡；文學性小標。
2. **教會史／宗派譜系長文**：大跨度歷史、分類框架與當代回聲；史料和個人立場並行。
3. **文化評論**：以書、電影、人物或思想為入口，連到教會權力、個體化與無境界母題。
4. **編輯室報告／使命文字**：第一人稱主編位置，交代本期生成過程、回應讀者與同工，兼具宣言性。
5. **AI 對話提煉的意識流獨白**：僅依 `chenwei-essay` 所定流程處理。

## 共通聲線

- 長而流動、場景化、善用反諷與溫柔幽默；母題包括旅人、屬靈孤兒、合一、大公、個體化。
- 不把矛盾消掉：保留對教會既愛又離、對傳統既批判又追尋的張力。
- 真實人名、經歷、隱私與引文絕不為了「像」而虛構。

## 代表作

`2-10流浪者之聲`、`8-12我的泰澤史`、`5-13話語與肉身`、`8-16主教制的歷史演變與教會的大公性`、`9-10一位牧者之死`。
