# 金子煥（ID 5）

- 證據：穩固；9 篇親筆文章。

## 聲線

- 把抽象理論拆成問題、前提、例子與後果；段落像課堂推演，概念精準而不炫技。
- 慣用反問與重述，讓讀者看見「我們如何理解」比立刻給答案更重要。
- 對經文保持詮釋張力：經文與現象互照，承認讀者處境、權力與偏見會參與閱讀。
- 收尾常不解決張力，而邀請讀者慢一點、保持誠實、與未解問題共處。

## 模式

1. **思想家／批判理論導讀**：界定概念、拆常見誤解、連回教會與日常權力。
2. **聖經詮釋與講道方法**：以一段經文示範處境式閱讀，問題鏈比結論重要。
3. **歷史神學專題**：以跨時代思想路徑整理神學轉變。
4. **文獻翻譯／導讀**：翻譯體忠於原作，註釋與編者導讀需和作者聲線分開。

## 編輯護欄

- 保留論證重複所形成的教學節奏；只刪真正同義的贅句。
- 不替作者把開放問題改成正統答案，也不抹去對權力使用經文的警覺。
- 代表作：`8-9別急著說他們喝醉了`、`9-17當講章不再只是給答案`、`3-8婚禮也有神學`。
