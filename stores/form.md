### 1.2 字體系統

#### 正文字體

| 用途 | 中文字體（eastAsia） | 西文字體（ascii/hAnsi） |
|------|---------------------|----------------------|
| 正文 | NSimSun（新宋體） | Times New Roman |
| 正文中的「‧」 | 新細明體（PMingLiU） | — |

> 說明：正文混用 Times New Roman 與 NSimSun，中文字走 NSimSun，西文走 Times New Roman。

#### 標題字體

| 元素 | 中文字體 | 西文字體 | 字號 | 粗體 |
|------|---------|---------|------|------|
| 大標題 | 華康中黑體 / Times New Roman | Times New Roman | 24pt | ✅ |
| 副標題（——XXX） | 華康中黑體 / Times New Roman | Times New Roman | 16pt | ✅ |
| 段落小標題 | NSimSun / Times New Roman | Times New Roman | 14pt | ✅ |

> 說明：大標題字體依文章而異。編輯室報告、目次、作者簡介、投稿資訊、編輯資訊、以及部分專題文章（如16）使用華康中黑體；其餘文章使用 Times New Roman。

#### 特殊用途字體

| 元素 | 中文字體 | 西文字體 | 備註 |
|------|---------|---------|------|
| 作者姓名 | 文鼎中行書 | Brush Script MT | 靠右對齊 |
| 作者頭銜／單位 | 文鼎中行書 | Brush Script MT | 靠右對齊 |
| 日期 | 文鼎中行書 | Brush Script MT | 靠右對齊，部分文章有 |
| 書摘／開場引言 | 文鼎粗鋼筆行楷 | Brush Script MT | 顏色：黑色（themeColor text1） |
| 行內引用（「」內） | 標楷體 | — | 引號本身用 Times New Roman |
| 獨立引用段落 | 標楷體 | — | 左縮排 ~24pt |
| 詩歌／經文引用 | 標楷體 | — | 置中對齊 |

- 顏色：黑色、文字1、較淺 35%（Word 主題色）

| 欄目 | 色碼 | 色名 |
|------|------|------|

### 1.5 裝飾線

#### 粗裝飾線（每篇文章標題下方）

- 樣式：thickThin 組合線（上 3pt + 中間空 1pt + 下 1pt）
- 顏色：黑色（dk1 scheme color）
- 寬度：約 397pt（跨文字區域）
- 位置：大標題後方的空行段落中
- 實作：Word 繪圖線條物件（drawing shape, `prstGeom prst="line"`）

#### 灰色細分隔線（段落區塊之間）

- 樣式：Word 水平線（HR）物件
- 尺寸：寬 481.9pt，高 1.5pt
- 顏色：#bfbfbf（淺灰）
- 無描邊
- 出現位置：目次（分區之間）、編輯室報告（各段落介紹之間）、編輯資訊（各區塊之間）

### 1.6 頁首

頁首內容放在文字方塊（drawing shape）中，字體為微軟正黑體 / Times New Roman，10pt，顏色 #262626（themeColor text1, themeTint D9）。

#### 雙數頁（左頁）

```
無境界者｜Vol. X（YYYY.MM-MM）        ← 無底線
 火燒島上的《耶穌傳》                   ← 有底線（底線用空格延伸至固定寬度）
```

- 第一行：刊名＋期數＋日期，無底線
- 第二行：本期主題名，有底線，用尾部空格延伸底線至固定寬度

#### 單數頁（右頁）

```
      05 聆聽被遺忘的苦難               ← 整行有底線
```

- 格式：6 個空格 + 文章編號 + 1 個空格 + 文章名 + 1 個空格
- 整行加底線（single underline）
- 底線長度隨文章名長短變化（前後空格撐出底線）
- 部分文章的前導空格使用全形空白（U+3000）

### 1.7 頁尾

- 內容：頁碼
- 位於頁面底部

## 二、文章類型與結構

### 2.1 一般文章（有欄目標籤）

以下類型共用相同的基礎結構：專題文章、人物專訪、評論與回應、生命故事、公告與剪影、時事評論、封面故事。

#### 標準結構模板

```
【欄目標籤】                  ← 14pt，各欄目專屬色，靠右，首行縮排 ~25.5pt
大標題                        ← 24pt 粗體，靠左
——副標題                      ← 16pt 粗體，靠左
────────────────────────────  ← 粗裝飾線（thickThin, 3pt+1pt+1pt）
（空行）
作者姓名                      ← 文鼎中行書 / Brush Script MT，靠右
作者頭銜／單位                ← 文鼎中行書 / Brush Script MT，靠右
日期                          ← 文鼎中行書 / Brush Script MT，靠右（部分有）
（空行）
🌿關鍵字：A、B、C、D、E       ← NSimSun 粗體
（空行 ×1~2）
段落小標題                    ← 14pt 粗體，段前段後各 ~9pt
正文段落...                   ← Times New Roman / NSimSun，1.25 倍行距
正文段落...
（重複：段落小標題 + 正文...）
圖片說明文字                  ← 10pt TNR / 新細明體，置中，色 #595959
（圖片來源：XXX）             ← 10pt TNR / 新細明體，置中，色 #595959
```

#### 各類型與標準模板的差異

##### 封面故事

- 欄目標籤字體：文鼎中行書（非 Times New Roman）
- 無副標題、無關鍵字
- 正文較短，散文體

##### 專題文章

- 最標準的格式，完全符合上述模板
- 部分文章使用自定義樣式「正文（中文）」

##### 人物專訪

- 開頭多一段「訪談簡介」（正文字體），結尾署名「──張辰瑋」（文鼎中行書，靠右）
- 有「受訪者簡介」段落
- 有影片/作品資訊區塊
- Q&A 對話格式：
  - 使用 No Spacing 樣式
  - 說話者名稱粗體（如「辰瑋：」「許導演：」），冒號後接正文（不粗體）
  - 說話者名稱與正文在同一段落中

##### 評論與回應

- 大量使用獨立引用段落（標楷體 + 左縮排 ~24pt）
- 部分文章有書摘/開場引言（文鼎粗鋼筆行楷 / Brush Script MT）
- 判決書等長篇引文：整段標楷體 + 左縮排

##### 生命故事

- 可能包含「舊文重刊」子區塊：
  - 用文鼎中行書標題（置中）
  - Brush Script MT 日期（靠右）
  - 重新標記原始寫作日期
- 包含大量講章引用（標楷體 + 左縮排，List Paragraph 樣式）
- 詩歌引用：標楷體，逐行排列
- 段落之間可能出現「※」分隔符號（置中）

##### 公告與剪影

- 偏心得分享體裁
- 段落小標題常為書名/課程主題名

##### 時事評論

- 兩期皆為【時事評論】，色碼 #0070C0
- 使用較多 List Paragraph（列點段落）
- 正文風格偏評論/議論體
- 時事評論類可能無副標題、無段落小標題（如 Vol. 6 文 08）

### 2.2 輔助頁面（無欄目標籤）

#### 目次

```
大標題「目次」                 ← 華康中黑體 24pt 粗體
────────────────────────────  ← 粗裝飾線
（空行）
01 編輯室報告｜編輯室｜pp. X   ← TNR 13pt，編號粗體
02 本期作者簡介｜編輯室｜pp. X
03 【封面故事】文章名｜作者｜pp. X   ← 【欄目】用各自色碼
────────────────────────────  ← 灰色細分隔線
（空行）
分區標題「特稿專區」           ← TNR 14pt 粗體，置中
04 【專題文章】文章名...
05 【人物專訪】文章名...
   ──副標題｜作者｜pp. X      ← List Paragraph 樣式
────────────────────────────  ← 灰色細分隔線
分區標題「主題廣場」           ← TNR 14pt 粗體，置中
...
```

- 目次條目中的【欄目名】使用該欄目的專屬色碼（如【封面故事】#833C0B）
- 「特稿專區」「主題廣場」等分區標題：14pt 粗體，置中
- 各分區之間用灰色細分隔線分隔
- 目次內文字號為 13pt

#### 編輯室報告

```

（空行）

正文段落...
────────────────────────────  ← 灰色細分隔線（各介紹段之間）
本期主題：「XXX」              ← 文鼎中行書 16pt 粗體，置中
正文段落...
────────────────────────────  ← 灰色細分隔線
本期各文章介紹...

```

- 各段落介紹之間用灰色細分隔線分隔
- 可能包含書摘引言（文鼎粗鋼筆行楷）

#### 本期作者簡介

```
大標題「本期作者簡介」         ← 華康中黑體 24pt 粗體
────────────────────────────  ← 粗裝飾線
（空行）

┌──────────┬────────────────────────────────┐
│ 作者照片  │ 作者姓名（14pt 粗體 TNR）        │
│          │ 個人簡介正文...                   │
├──────────┼────────────────────────────────┤
│ 作者照片  │ 作者姓名                         │
│          │ 個人簡介正文...                   │
└──────────┴────────────────────────────────┘
分區標題「本期專欄作者」
（同上表格格式）
（作者依照文章先後順序排列）   ← 9pt，靠右
```

- 使用 2 欄表格：左欄放作者照片，右欄放姓名（14pt 粗體）+ 簡介
- 分成多個表格：特邀作者、主編、專欄作者


## 三、跨類型共用的特殊格式

### 3.1 引用格式

#### 行內引用

- 引號「」內的引用文字使用**標楷體**
- 引號本身和前後正文維持 Times New Roman / NSimSun
- 範例：正文正文「**標楷體引用內容**」正文正文

#### 獨立引用段落

- 整段使用**標楷體**
- 左縮排 ~24pt（約 0.85cm）
- 行距維持 1.25 倍
- 常見於書籍原文引用、判決書引文、獄中書簡等長篇引文
- 使用 List Paragraph 或 Normal (Web) 樣式

#### 詩歌／經文引用

- **標楷體**，置中對齊，無縮排
- 每行一段（逐行排列）
- 出處署名靠右對齊
- 範例：
  ```
  （置中）詩歌第一行
  （置中）詩歌第二行
                        ──出處（靠右）
  ```

#### 題詞引用

- **標楷體**，10pt，顏色 #808080（灰色）
- 置中對齊
- 用於文章段落間的點題引文

#### 書摘／開場引言

- 中文字體：**文鼎粗鋼筆行楷**
- 西文字體：**Brush Script MT**
- 顏色：黑色（themeColor text1）
- 出現在編輯室報告和部分評論文章

### 3.2 圖片說明

- 字體：Times New Roman / 新細明體（PMingLiU）
- 字號：10pt
- 顏色：黑色、文字1、較淺 35%（近似 #595959）
- 對齊：置中
- 通常兩行：第一行為圖片描述，第二行為（圖片來源：XXX）

### 3.3 分隔符號

- 「※」符號：Times New Roman，置中對齊
- 用於生命故事等類型中，標記段落的轉折或分隔

## 七、固定作者檔案

### 7.1 張辰瑋（主編）

- 頭銜：國立台北教育大學台灣文化研究所碩士
- 出現期數：Vol. 6、Vol. 7（每期必有）
- 文章數量：每期 2–3 篇，外加編輯室報告
- 慣用欄目：評論與回應、專題文章、生命故事
- 字數範圍：約 8,000–13,000 字（長文型作者）
- 行文風格：學術半學術體裁，善用大量引用（標楷體段落頻繁出現），論述結構嚴謹，段落小標題清晰。書評類文章會搭配書摘引言（文鼎粗鋼筆行楷）。個人敘事與學術分析並重，常在前言以第一人稱分享個人經歷後轉入學術討論。
- 圖片使用：每篇約 5–9 張，包含歷史照片、書影、Gemini 生成圖。圖片說明詳細，常附出處。
